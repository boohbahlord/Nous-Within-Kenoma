## PART B — DIGESTION (for me)

### Principles I read in this (the patterns behind the complaints)
1. **Playability first.** Essential controls (board, hand, Selected panel, spells) must be reachable without page scrolling on desktop.
   Long lists live in their own scroll boxes with a themed scrollbar that grows/shrinks with the content. Never make the player hunt.
2. **Organization = consistent order + consistent geometry.** Same-size tiles in a group (maps, substances, sky). Lists in a meaningful
   order (spells by price within a category; Ether shop by category, then cheapest first). One card = one type.
3. **English is a priority.** Concise, accurate, purposeful; proper capitalization; no stray quotation marks; consistent naming
   (1v1 / 2v2, P1, "Increase Max Mana" not "Buy ..."). Organization, English and purpose are one trinity: a clear label in a clear place
   for a clear reason.
4. **Information on demand, not walls of text.** Option tiles show a name (and maybe one short line); the explanation appears on hover
   (desktop) or on a tap-info control with an X (mobile). Think a ribbon in Word, not paragraphs in buttons.
5. **Scale-safe text.** Text Size grows small/detail text the most, headings barely, with hard caps; layouts must keep order at the
   user's settings (Text 180%, UI 80%, full width). A clipped label is worse than a smaller font. Don't just shrink everything.
6. **Desktop gets room.** Wide layout by default on a computer; windows (Bank, Ether, setup) wider and taller.
7. **Keep what was good.** The v12-era look (simple bordered spell rectangles, dark palette, mono font) stays. No generic templates.
   Don't redo everything.
8. **Care in details.** Every window gets a top-right X (plus its close button). Nothing overlaps (the Static toggle). Disabled things
   look disabled (faded dropdowns when nothing to choose). Text doesn't float next to unrelated UI.
9. **Card faces follow one system.** Top-left symbol + bottom name for every card; same ink and line weight as the standard cards.
10. **Don't jump ahead.** Do this in parts, each part finished properly and checked by eye at the user's settings.

### My order of work (and why this order)
Playability blocks testing everything else, so the play screen comes first. English second (it touches every text, and the setup
menu's redesign depends on the new short texts). Setup menu third (needs the new texts and the tile/hover-info pattern from part 1).
Card faces fourth (independent, visual).
