## Hidden cards in online games (decided 2026-10-23: leave it for now)

- In an online game the host's browser sends every joined player the whole game: other players' hands, the order of
  the decks and face-down cards. The screen hides them, but anyone can read them with the browser's developer tools.
- The fix: the host sends each player a copy with the hidden parts blanked out. It changes how online games stay in
  step, so it needs careful testing (risk of new online bugs).
- The user's choice: (b) leave it for now, and be reminded later, maybe days or more later. Do it before the game is
  played online with strangers.
